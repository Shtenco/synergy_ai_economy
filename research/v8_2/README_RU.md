# СИНЕРГИЯ — РОССИЯ V8.2: денежный контур, честный OOS и проверка IO

**Статус:** исследовательский исполняемый прототип, опубликован 15.10.2026. **Эмпирическая калибровка не пройдена.** Это не цифровой двойник России, не воспроизведение СССР и не доказательство превосходства одной системы.

## Чем V8.2 отличается от V8.1

1. В банковском слое появились **отдельные наличные деньги M0**, банковские депозиты, кредиты домохозяйствам, проценты, выдача и погашение долгов; соответствующие операции связаны встречными записями в балансах банков и Банка России.
2. Для модельного приближения М2 теперь используется `deposits + currency_outside_banks`; это лучшее определение, чем сравнение одних депозитов с М2, но **не тот же статистический агрегат** из-за неполного охвата экономических агентов.
3. У кредитования домохозяйств есть собственные ограничения по обеспечению платежей, нормативу капитала банка и доступной ликвидности, без «напечатанной» банковской прибыли.
4. Сохранены четыре строя (капитализм / СССР-подобное планирование / современная смешанная РФ / кибернетическая СИНЕРГИЯ), четыре общедоступные политики (baseline / escrow / demand / escrow_demand), физический отраслевой баланс 8 секторов, идентичные случайные шоки и эскроу-эмиссия под банковское соинвестирование 1:1.
5. Эксперименты формируют отдельные выгрузки TRAIN-калибровки, OOS 2023–2025, разницы политик, межотраслевой неопределённости, активного кредитования домохозяйств и проверочных инвариантов.

## Критический статус отраслевой матрицы

**Фактическую матрицу Росстата так и не удалось извлечь из официальных XLSX.** Росстат действительно публикует базовые таблицы «затраты–выпуск» за 2016 и 2021 годы на https://www.rosstat.gov.ru/statistics/accounts . Также доступна альтернативная статистика OECD ICIO: https://www.oecd.org/en/data/datasets/inter-country-input-output-tables.html . Однако локально подтверждённого оригинального файла и достоверной нормализованной таблицы по отраслям нет. Поэтому `economy_v81_legacy.A` **остаётся иллюстративной матрицей**. Запрещено маркировать её оценкой России. `src/io_ingest.py` требует оригинальный файл, его SHA256, полное соответствие кодов продуктов и балансовых строк, после чего строит A при самостоятельной проверке пользователем методики нормализации.

## TRAIN и OOS без подгонки будущего

- TRAIN 2016–2022: денежная калибровка — рост М2 2019→2022 по вторичной републикации официальных данных; фискальный масштаб наследуется из V8.1, откалиброванный только на 2019–2022.
- `credit_rate` и `household_amortization` выбираются из заранее заданной сетки 5×3 по четырём TRAIN-seed 7000–7003. Заморозка записана в `results/train_frozen_v82.json`.
- OOS 2023–2025: 12 новых семян 9800–9811, 4 системы × 4 политики × 2 стресс-режима → **384 прогона**, 120 месяцев каждый; сравнение накопленного физического выпуска и потребления только за последние 36 месяцев. Текущий курс USD/RUB наблюдается только в конце соответствующего шага.
- Стабильность к неизвестной фактической IO-матрице: 144 симуляции с множителем 0.8/1.0/1.2 над иллюстративными коэффициентами.
- Контрфакт потребительского кредитования: 128 прогонов с `credit_rate=0` и `credit_rate=.01` в тех же макросценариях.
- **Итого 716 запусков:** 60 TRAIN + 384 основных + 144 IO + 128 кредитных.

## М2: исправили охват бухгалтерии, но не прошли калибровку

| Метрика TRAIN 2019→2022 | Значение |
|---|---:|
| Наблюдаемый рост М2 (вторичный ряд) | **×1.56240** |
| Лучшее `deposits+M0` в модели | **×1.03616** |
| Абсолютная логарифмическая ошибка | **0.41081** |
| Условие `<10%` относительной ошибки | **FAIL** |
| Выбранный тренингом кредитный коэффициент домохозяйств | **0** |

**Важная отрицательная находка:** лучший параметр кредитования домохозяйств в текущем модельном устройстве равен нулю. Прямое принуждение домохозяйств к новым кредитам в абляции 128 прогонов не устранило несоответствие М2 и при этом уменьшило физический выпуск. Это признак структурного дефекта модели, а не «решение» адаптацией.

**Почему нельзя форсировать:** эмиссия по нормативу желаемого М2 создаёт ложное подтверждение, если не смоделированы реальные контрагенты: обязательства ЦБ, рефинансирование, бюджетные операции, балансы банков, кредиты небанковскому сектору, экспорт/импорт и структура вкладов. Модель именно эти недостающие контуры и должна строить следующими.

Росстат и Банк России публикуют разные по охвату статистики. М2 = рублёвая наличность вне банков и рублёвые депозиты небанковских резидентов, см.: https://www.cbr.ru/statistics/macro_itm/dkfs/methodological_commentary_ms/ . Исторические М2 в локальном CSV — **неофициальный републикованный вторичный ряд**, а не выгрузка официального динамического архива.

### Синтетическая банковская устойчивость

В новом наборе кризисные OOS-сценарии нередко дают 0 банковских санаций из-за высоких модельных капиталов и частоты выходов. Это **не подтверждение надёжности банков РФ**. Банковские веса, структура активов и реальные нормативы обязательны к отдельной калибровке. Проверка равенства записей не является проверкой макроэкономической реалистичности.

## Аудит

- В 384 основных запусках: максимальное абсолютное нарушение финансовой двойной записи `1.82×10^-11` (условные денежные единицы); физического баланса `4.55×10^-13` (условные товары); `released_escrow == matched_bank_cofinance` с нулевым расхождением.
- 8/8 unit-тестов операций банков и денежного обращения.
- **Условная 95%-я CI** вычислена для парных разностей между политиками по 12 seed. Бутстрэп не доказывает неслучайность структурного смещения модели.
- Реальные данные 2023–2025 и ФАКТИЧЕСКИЕ отраслевые доли не передаются контроллеру. Реализованный курс USD/RUB на текущем месяце становится известен только после выполнения решений.

## Исполнение

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python src/run_v82.py --seeds 12 --calibration-seeds 4 --io-seeds 3
python make_report.py
```

`src/run_v82.py` при полном запуске произведёт TRAIN, MAIN и IO; контрфакт кредитования в отдельном `src/household_credit_ablation.py`. В ZIP результаты уже сохранены.
